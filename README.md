# ML Integration Lab 1

Учебный проект практической работы 1 по дисциплине «Разработка и интеграция».
На этом этапе в репозитории зафиксированы структура каталогов, безопасная копия
исходной исследовательской заготовки и список зависимостей. Код обучения,
предсказания, тесты и полная инструкция запуска добавляются следующими коммитами.

## Структура

```text
ml-integration-lab/
├── README.md
├── .gitignore
├── requirements.txt
├── notebooks/source_experiment.ipynb   # очищенная копия исходной заготовки
├── data_sample/sample.csv              # один тестовый объект Iris
├── models/                             # артефакт модели (создается обучением)
├── src/                                # обучение и предсказание
└── tests/                              # минимальная проверка запуска
```
