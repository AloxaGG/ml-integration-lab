ML Integration API

Учебный сервис классификации ирисов: FastAPI-приложение загружает сохранённую модель и отдаёт предсказание по маршруту POST /predict.

Схема openapi.json не хранится в репозитории: она генерируется в CI/CD вызовом app.openapi() и поэтому всегда соответствует коммиту, из которого собран сайт.
